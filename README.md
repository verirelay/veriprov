# VeriProv

VeriProv 是 VeriRelay 的运行配置下发服务：机密虚拟机通过远程证明后，才能拿到运行配置，比如 admin token 和 store 密码。

VeriProv is the Runtime Config Provisioning service for VeriRelay: a CVM receives Runtime Config such as the admin token and store passwords only after it passes Attestation.
